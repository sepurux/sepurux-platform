# AGENTS.md

## Goal
Revamp this website into a premium, modern, visually sophisticated product site without breaking product behavior.

## Working style
- First understand the product from the codebase before proposing design changes.
- Do not rush into implementation.
- Audit, propose, then implement.
- Favor clean, maintainable, production-grade code.
- Do not introduce unnecessary dependencies unless clearly justified.

## Design standards
- Premium, credible, modern, not template-looking
- Strong typography hierarchy
- Excellent spacing rhythm
- Clear CTA flow
- Elegant visual restraint
- Mobile-first responsiveness
- Accessible contrast and semantics
- Tasteful motion only

## Avoid
- Generic startup gradients
- Random glassmorphism everywhere
- Oversized padding with weak information density
- Cartoonish visuals
- Unstructured landing-page filler
- Overly flashy animations
- Breaking current business logic

## Implementation expectations
- Reuse existing architecture where sensible
- Improve weak components decisively
- Keep styles consistent across pages
- Create reusable UI primitives if needed
- Keep components readable and modular

## Deliverables
1. Site audit
2. Three visual directions
3. Chosen direction with rationale
4. Implementation plan
5. Code changes
